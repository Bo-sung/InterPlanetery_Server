## 2. 게임 시작 플로우 (완성된 버전)

```mermaid
sequenceDiagram
    participant Client as 클라이언트
    participant Session as ClientSession
    participant Room as GameRoom
    participant Game as Game Instance
    participant Player as GamePlayer

    Client->>Session: REQUEST_READY (10014)
    activate Session
    Session->>Room: HandleOnReady()
    activate Room

    alt 모든 플레이어 레디
        Room->>Game: StartGame(mapId)
        deactivate Room
        activate Game

        Game->>Game: LoadMapData()
        Game->>Game: BroadcastGameSet()
        Game->>Player: Async_SendGameSet(mapData)
        activate Player
        Player->>Client: GAME_SET (20200)
        deactivate Player

        Client->>Player: REQUEST_GAME_CL_READY (10200)
        activate Player
        Player->>Player: OnUserReady.Invoke()
        deactivate Player

        Game->>Game: WaitUntilUsersReadyAll()
        Note over Game: 최대 15초 대기<br/>모든 플레이어 OnUserReady 수신

        Game->>Game: GameState 초기화
        Game->>Game: BroadcastGameStart()
        Game->>Player: Async_SendGameStart()
        activate Player
        Player->>Client: GAME_STARTED (20201)
        deactivate Player

        Game->>Game: GameLoop 시작
        Note over Game: 20 TPS<br/>50ms 고정 틱

    else 15초 타임아웃
        Game->>Game: LogWithTimestamp(timeout)
        Game->>Game: 강제 게임 시작
    end

    deactivate Game
    deactivate Session
```

## 6. 명령어 큐 시스템

```mermaid
sequenceDiagram
    participant Client as 클라이언트
    participant Session as ClientSession
    participant Game as Game.EnqueueCommand
    participant Queue as m_commandQueue
    participant Executor as CommandProcess

    Client->>Session: SUBMIT_COMMAND (30100)
    activate Session

    Session->>Game: SendCommandToGame(command)
    activate Game

    Note over Game: currentTick = 10<br/>targetTick = 10 + 3 = 13

    Game->>Queue: commandQueue[13].Add(command)
    deactivate Game

    Note over Queue: 큐에 대기<br/>3틱 네트워크 버퍼

    Note over Executor: 틱 13 도달

    Executor->>Queue: Get commandQueue[13]
    activate Executor

    alt 명령어 존재
        Executor->>Executor: HandleProduceFleet / HandleMoveFleet
        Note over Executor: 명령어 실행
    end

    Executor->>Queue: Remove commandQueue[13]
    deactivate Executor
    deactivate Session
```
